# Video Cut（开发中）

Video Cut 是面向 Windows 和剪辑新手的视频切片工具，基于 [LosslessCut](https://github.com/mifi/lossless-cut) 开发。它适合从一段长视频中挑出许多短片段，命名后分别导出，便于查找、整理和后续拼接。

本项目不是 LosslessCut 官方发行版。源代码使用 GPL-2.0-only，详见 [LICENSE](LICENSE)。

## 当前功能

- 简体中文默认界面。
- 在一个视频项目中标记、命名和整理多个片段，并将片段分别导出到项目目录。
- 保存片段项目，稍后继续整理。
- 为单个片段添加文字，设置显示时长；文字可在预览中查看，导出时烧录到画面。
- 为单个片段绑定 SRT 字幕并在预览中查看；也可在导出选项中选择 SRT、ASS 或 SSA 字幕烧录到选中的片段。
- 将选中的片段导出为循环 GIF。默认使用 640 像素宽度和 12 帧/秒，并自动生成调色板。
- 从视频中截取原始分辨率图片。
- 默认快速复制视频流；添加文字或烧录字幕时会重新编码视频，尽可能沿用原视频码率。

## 快速使用

1. 打开长视频并播放或拖动时间轴，找到想保留的内容。
2. 设置片段的开始和结束位置，添加片段并为它命名。重复此操作可整理多个片段。
3. 可选：为当前片段添加文字、设置显示时长，或绑定 SRT 字幕。
4. 选择导出格式和输出目录，再导出片段。文件名可用片段顺序、名称和开始时间帮助识别。
5. 使用项目文件保存切片列表，之后可以继续修改和导出。

文字和烧录字幕需要重新编码，导出会比快速切片更慢。沿用原视频码率是尽量保持相近体积的默认策略，实际输出大小仍会受编码器和画面内容影响。GIF 体积提示为粗略估算。

## 当前限制

- 片段字幕绑定和预览目前支持 SRT；导出窗口另支持 SRT、ASS、SSA。
- 文字的位置、字号和样式固定，文字从片段开始时显示。
- GIF 的体积会随画面运动和颜色变化，导出页估算不代表最终文件大小。
- 项目仍在开发中，Windows 安装包尚未发布。请在 GitHub 的 [Releases](https://github.com/Ruefmiia/video-cut/releases) 页面查看正式版本。

## 从源码运行

需要安装 Node.js 和 Yarn 4。克隆仓库后，在项目目录运行：

```powershell
yarn install
yarn dev
```

生成 Windows x64 ZIP：

```powershell
yarn pack-win
```

Windows 打包需要下载 Electron Builder 工具和仓库配置的 FFmpeg。网络无法访问下载源时，打包可能失败；请查看 [开发计划](DEVELOPMENT_PLAN.md) 中的当前构建状态。
